# AI-Powered Meeting-to-Action Assistant (M1-P2)

## Overview
This project is an autonomous meeting assistant that parses raw meeting transcripts into structured meeting summaries, key decisions, assigned tasks, and deadlines. It automatically flags incomplete or ambiguous action items that require clarification.

## Features
- **Transcript Parsing**: Extracts key takeaways from conversational dialogue.
- **Decision Tracking**: Identifies agreed-upon decisions.
- **Action Item Extraction**: Maps out assigned tasks and tracks timeline commitments.
- **Ambiguity Detection**: Highlights action items missing clear deadlines or assignees.
